# Documentacion

Este directorio concentra documentacion tecnica generada durante el desarrollo
(distinta de `docs/lineamientos.md`, que es el documento normativo del proyecto).

## Indice
- `arquitectura.md`: decisiones de arquitectura de la Fase 1 y su justificacion.

## Convencion
Cada decision tecnica relevante (stack, libreria nueva, cambio de estructura)
debe registrarse aqui con su justificacion, siguiendo CLAUDE.md.
